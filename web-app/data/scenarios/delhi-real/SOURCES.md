## Overpass usage
Four queries in total (2026-11-25), one at a time, generic User-Agent `cb-realmap/1.0`, no keys or accounts; the
public server answered HTTP 502 ("at capacity") a few times and the script waited 30 s, then 60 s before retrying (exponential
backoff). Responses are cached, so reruns (`--offline`) send nothing. No user, project or organisation data was sent; only the
queries. The Overpass usage-policy page was not re-read during this run; re-check it before any further bulk use.

## Not included
- Real organisation names: the displayed names are imitations ("<Type> · <locality> #n"). The OSM element id of each source
  place is kept only in `tools/realmap/output/delhi_real_meta.json`.
- Basemap tiles (the web app chooses its own tile source and must follow that source's usage policy).
- Live traffic: travel times are a speed model, not measured.
- The raw Overpass responses (`tools/realmap/cache/`, about 16 MB) are not part of the repository. `build_delhi_real.py` fetches them again when they are missing; the output is then rebuilt from the new download.
